First public release (1.0.0). Semantic tokens and brand themes generated from a small JSON file with WCAG 2.2 AA
checks at build time, a Tailwind v4 layer, a shadcn/ui bridge and a UI linter; accessible React primitives; zero-JS
Astro marketing components; the motion system with reduced-motion handling, character presets and spring drivers;
and the anti-AI design rules, detector and example pairs.
