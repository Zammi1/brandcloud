# Changelog

Each package keeps its own `CHANGELOG.md`, written by [Changesets](https://github.com/changesets/changesets) when a
release is versioned. Pending changes are in `.changeset/`.

## 1.0.0 (unreleased)

The first public release. See `.changeset/first-public-release.md`. Until it is versioned, packages carry the
pre-release number 0.9.0 and are marked private so nothing can be published by accident.
